# 🍂 가을 어느날 운명 — 중앙 서버 버전

기존 PeerJS 방식 대신 Netlify Functions + Netlify Blobs를 사용합니다.
따라서 방장 휴대폰이 다른 앱으로 이동하거나 백그라운드가 되어도 방 자체가 방장 브라우저에 종속되지 않습니다.

## 배포
1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. Netlify에서 해당 저장소를 연결해 배포합니다.
3. Build command는 비워 두고 Publish directory는 `.`로 둡니다.
4. `package.json`이 있으므로 `@netlify/blobs`가 설치됩니다.
5. 배포 후 기존 `sadari-01.netlify.app` 주소를 유지하려면 기존 사이트에 연결하거나 도메인/사이트 설정에서 동일 주소를 사용합니다.

## 동작
- 방 코드는 00~99
- 방장 포함 2~16명
- 참가자는 방장과 독립적으로 서버에 접속
- 1초 간격으로 상태를 확인
- 동시에 같은 번호를 선택해도 서버가 먼저 성공한 요청만 인정
- 참가자 전원이 번호를 선택하면 남은 번호가 방장에게 자동 배정
